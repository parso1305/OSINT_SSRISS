# Section 1: Structured Failure Logging Examples

This document records the actual captured logs generated by the structured logging pipeline (`src/logging_config.py` and `src/runner.py`) for a successful run and 5 failure/anomaly conditions.

Each entry uses consistent, grep-able `key=value` tokens allowing automated monitoring and log aggregation tools to immediately determine the stage (`fetch`, `parse`, `normalize`, `store`), severity (`WARNING` vs `ERROR`), source, and underlying exception without reading source code.

---

## Baseline: Successful Pipeline Run

```text
2026-09-17 01:13:47 [INFO] START source=iit_bombay
2026-09-17 01:13:47 [INFO] FETCH url=https://www.iitb.ac.in/events status=200 duration_ms=0
2026-09-17 01:13:47 [INFO] PARSE records=3
2026-09-17 01:13:47 [INFO] NORMALIZE records=3
2026-09-17 01:13:47 [INFO] STORE new=3 existing=0 changed=0
2026-09-17 01:13:47 [INFO] END duration_ms=64
```

---

## Case 1: Invalid URL

- **Failed Stage**: `fetch`
- **Severity**: `ERROR` (Run-aborting)
- **Error Type**: `InvalidURL`
- **Cause**: The crawl URL fails RFC URL grammar or lacks a host / scheme.
- **Actual Captured Log Output**:

```text
2026-09-17 01:13:47 [INFO] START source=iit_bombay
2026-09-17 01:13:47 [ERROR] FAILURE source=iit_bombay url=http:// stage=fetch error_type=InvalidURL message="Invalid URL 'http://': No host supplied"
```

---

## Case 2: Connection Failure

- **Failed Stage**: `fetch`
- **Severity**: `ERROR` (Run-aborting)
- **Error Type**: `ConnectionError`
- **Cause**: The remote target is unreachable, network connection refused, or host cannot be resolved.
- **Actual Captured Log Output**:

```text
2026-09-17 01:13:47 [INFO] START source=iit_bombay
2026-09-17 01:13:49 [ERROR] FAILURE source=iit_bombay url=http://127.0.0.1:59999/events stage=fetch error_type=ConnectionError message="HTTPConnectionPool(host='127.0.0.1', port=59999): Max retries exceeded with url: /events (Caused by NewConnectionError('<urllib3.connection.HTTPConnection object at 0x0000017B0424D6A0>: Failed to establish a new connection: [WinError 10061] No connection could be made because the target machine actively refused it'))"
```

---

## Case 3: Parser Receiving Unexpected HTML (Site Redesign)

- **Failed Stage**: `parse`
- **Severity**: `ERROR` (Run-aborting)
- **Error Type**: `StructuralError`
- **Cause**: The remote site underwent a structural redesign; expected container `.view-events-listing` and card hierarchies are missing. Fails loudly instead of silently returning empty data.
- **Actual Captured Log Output**:

```text
2026-09-17 01:13:49 [INFO] START source=iit_bombay
2026-09-17 01:13:49 [INFO] FETCH url=https://www.iitb.ac.in/events status=200 duration_ms=0
2026-09-17 01:13:49 [ERROR] FAILURE source=iit_bombay url=https://www.iitb.ac.in/events stage=parse error_type=StructuralError message="Structural layout mismatch: Target container '.view-events-listing' not found in HTML. Site structure may have changed."
```

---

## Case 4: Empty Listing (Recoverable)

- **Stage**: `parse`
- **Severity**: `WARNING` (Recoverable anomaly — pipeline continues cleanly)
- **Error Type**: None (Non-fatal)
- **Cause**: The target page loaded successfully and contains the valid listing container, but has 0 event items scheduled (e.g. vacation period, search filter with no matches).
- **Actual Captured Log Output**:

```text
2026-09-17 01:13:49 [INFO] START source=iit_bombay
2026-09-17 01:13:49 [INFO] FETCH url=https://www.iitb.ac.in/events status=200 duration_ms=0
2026-09-17 01:13:49 [WARNING] WARNING source=iit_bombay url=https://www.iitb.ac.in/events stage=parse message="Empty listing: container exists but contains zero event cards"
2026-09-17 01:13:49 [INFO] PARSE records=0
2026-09-17 01:13:49 [INFO] NORMALIZE records=0
2026-09-17 01:13:49 [INFO] STORE new=0 existing=0 changed=0
2026-09-17 01:13:49 [INFO] END duration_ms=14
```

---

## Case 5: Database Write Problem

- **Failed Stage**: `store`
- **Severity**: `ERROR` (Run-aborting)
- **Error Type**: `DatabaseError`
- **Cause**: The storage layer encountered a non-functional or corrupted database file, preventing schema creation and record insertion.
- **Actual Captured Log Output**:

```text
2026-09-17 01:13:49 [INFO] START source=iit_bombay
2026-09-17 01:13:49 [INFO] FETCH url=https://www.iitb.ac.in/events status=200 duration_ms=0
2026-09-17 01:13:49 [INFO] PARSE records=3
2026-09-17 01:13:49 [INFO] NORMALIZE records=3
2026-09-17 01:13:49 [ERROR] FAILURE source=iit_bombay url=https://www.iitb.ac.in/events stage=store error_type=DatabaseError message="file is not a database"
```
